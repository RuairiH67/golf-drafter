## What works today

- **Spring Boot REST API** with an endpoint that calculates four-ball
  match play strokes.
- **Strokes off the low man.** Given any group of course handicaps and an
  allowance, calculates the strokes each player receives.
- **Four-ball match play.** Applies the 90% allowance from Appendix C of the
  Rules of Handicapping and requires exactly four players.
